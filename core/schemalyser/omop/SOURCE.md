# OMOP CDM 5.4 field definitions

`cdm54_fields.csv` lists the tables and fields of the OMOP Common Data Model, version 5.4: each field's name, whether it is required, its data type, whether it is the primary key, and the domain its concept must belong to where the model names one.

It was taken on 3 October 2026 from the OHDSI CommonDataModel repository, file `inst/csv/OMOP_CDMv5.4_Field_Level.csv` (<https://github.com/OHDSI/CommonDataModel>). Only those six columns were kept, and the guidance text in the original was left out.

GitHub does not report a licence for that repository. The file here holds only the names, types and required flags of the fields of a published standard, which are facts about the standard. Whoever publishes this project should confirm that they are content with that.
